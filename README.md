# Машинное обучение

## Что это

В репе представлены лабы по СИИиМО 2025. В лабах ведется работа с датасетом "California_Houses_15_col_dot.csv". Отчеты представлены в книжках **.ipynb*.

В трех лабораторных ведется:

1. Первичный анализ датасета, построение банальных линейный моделей (МНК) при различных сочетаниях признаков.
2. Использование линейной модели стохастического градиентного спуска, влияние нормализации/стандартизации на выходные характеристики.
3. Построение полносвязных нейронных сетей. Исследование влияния структуры и параметров обучения на результаты. 

## Как работать

Для быстрого развертывания используется `conda`, настройки окружения приведены в *environment.yml*.
Для этого достаточно вызвать `conda env create -f environment.yml`.
Список окружений - `conda env list`
Сменить окружение - `conda activate <name>`
