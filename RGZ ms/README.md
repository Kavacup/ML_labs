## Ход работы
1. Проведение предварительного анализа исходного *.csv-файла: выполнение всех этапов подготовки данных из ЛР №1.
2. Проведение корреляционного анализа.
3. Построение линейной регрессионной модели от ОДНОГО признака, который выберет LLM (одномерной модели).
4. Построение линейной регрессионной модели от нескольких признаков (переменных) в соответствии с рекомендацией от LLM и выполнение анализа значимости и вклада выбранных признаков.
5. Построение регрессионной модели на основе многослойного персептрона той архитектуры, которую «посоветует» LLM.
6. Сравнение персептронов (первый из ЛР-2, второй - модель, сгенерированная LLM).
7. Подведение итогов в виде обоснованного вывода об эффективности применения LLM для предварительного анализа и построения моделей регрессии. Самостоятельно предложите критерии, по которым будет выполнена оценка эффективности.
